# Archive policy

Archive folder for historical, point-in-time, or incident-specific materials.

## What belongs here

- One-off outage notes and hotfix walkthroughs.
- Point-in-time deployment snapshots.
- Temporary troubleshooting playbooks superseded by canonical docs.

## Current archive candidates

- `DEPLOYMENT_STATUS.md`
- `GRAFANA_PORT_FIX.md`
- ad-hoc fix scripts at repo root used for one-off incidents

## Rule

If a document is not a durable setup, operation, or architecture reference, do
not keep it as a top-level canonical document.
